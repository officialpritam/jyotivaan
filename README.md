# JyotiVaan

Landing page for **JyotiVaan – Guidance for a Better You**, a Vedic astrology, numerology and Vastu consultation service.

Built with plain HTML, CSS and JavaScript plus these CDN libraries:

- [Swiper](https://swiperjs.com/) – testimonials slider
- [AOS](https://michalsnik.github.io/aos/) – scroll animations
- [Typed.js](https://github.com/mattboldt/typed.js) – hero typing effect
- [CountUp.js](https://inorganik.github.io/countUp.js/) – stat counters
- [Flatpickr](https://flatpickr.js.org/) – booking date picker
- Font Awesome, Google Fonts (DM Serif Display, Poppins)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 5510
```

Then visit http://localhost:5510.

## Structure

